# Ludo Privacy Policy site

This is a standalone GitHub Pages site for the Ludo app privacy policy. The policy page is `index.html`, so it is served at the repository's root URL.

## Publish as a separate public repository

1. Create a **public** GitHub repository named `ludo-privacy-policy` (or another available name).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish, then open the URL shown on that Pages settings screen in a private browser window.
6. Put that public page URL into Google Play Console under **App content → Privacy policy**.

Review and update `index.html` whenever the app's SDKs or data practices change.
